# 인천항 검역 시스템 · 운영 화면

## 실행

ZIP을 풀고 `index.html`을 Chrome 또는 Edge에서 엽니다. 엑셀 처리와 기준자료 조회는 로컬 파일로 동작합니다. 현재 날씨 조회에는 인터넷이 필요하며, 웹 폰트를 읽지 못하면 시스템 글꼴을 사용합니다.

GitHub Pages에 올릴 때는 이 폴더의 **내용 전체와 하위 폴더 구조**를 함께 올립니다. `index.html`만 올리면 데이터와 엑셀 읽기가 동작하지 않습니다. 이번 작업에서는 GitHub 게시나 배포를 하지 않았습니다.

## 사용 흐름

1. 필요하면 조회 기준 연월을 고릅니다.
2. 엑셀·CSV를 업로드합니다. 항만과 물동량 열을 자동으로 찾으면 같은 탭의 검역 현황 화면으로 이동합니다. 여러 시트 중 `port_month`가 있으면 먼저 선택합니다. 자동 인식이 안 되면 읽을 시트와 열 연결을 직접 지정합니다.
3. 전체 표에서 국가·항만·물동량·검사량·물동량 출처를 확인합니다.
4. 위 가로 항만 목록이나 표의 항만 이름을 누르면 종별 서식 적합도, 전월 검사량 비교, 현재 날씨와 다음 달 예상 물동량 입력창을 표시합니다. `전체 항만`으로 표에 돌아갑니다.

`기준자료 열기`는 제공된 과거 자료를 조회합니다. 연월을 고르지 않았다면 가장 최근 자료 월을 사용합니다. 파일 업로드 내용은 서버로 전송하거나 브라우저에 영구 저장하지 않습니다. 날씨 서비스에는 선택 항만의 좌표를 전송합니다.

## 운영 엑셀 열

기본 열은 `port_id, year, month, empty_teu`입니다. `운영자료_양식.csv`에는 열 제목만 들어 있습니다.

- `port_id`: 기준 항만 코드(예: `CNSHG`). 알려진 한글 항만 이름도 읽을 수 있습니다.
- `year`, `month`: 연도와 월. 하나의 `period` 또는 `연월` 열에 `YYYY-MM`로 넣어도 됩니다.
- `empty_teu`: 공컨테이너 물동량(TEU). 숫자 0은 유지하고 빈칸·잘못된 숫자를 0으로 바꾸지 않습니다.
- 선택 열: `country`, `inspection`, `previous_inspection`, `volume_source`, `species`, `lat`, `lon`.

연월 열이 없는 단일 월 파일은 등록 당시 선택한 기준월(미선택 시 현재월)에 배정합니다. 이후 월을 바꿔도 같은 자료를 다른 월의 자료로 재사용하지 않습니다. 같은 항만·연월의 여러 행은 합산합니다. 합산 대상 중 검사량이나 물동량이 비어 있으면 해당 합계는 결측으로 남깁니다.

기준목록 밖 항만은 입력한 이름으로 표에 남깁니다. 해당 항만의 적합도와 좌표가 없으면 자료 없음으로 표시합니다. 제공된 통합 엑셀의 `volume_source=none/n/a`이며 물동량이 비어 있는 행은 기후용·미제공 행으로 안내하고 입항 표에서 제외합니다. 명시된 0 TEU 항만은 유지합니다.

## 연결한 기준자료

- 항만 185개(해외 175, 국내 10), 후보 110종 중 분석 대상 74종
- 물동량·기후 자료 2016.01–2026.09. 실측/추정/업로드 구분을 화면에 표시
- 모델 88종의 원본 S 자료에서 분석 대상 74종의 값 429,200개를 월별 파일로 분리. 원본 수치의 정밀도를 유지
- 계획 연월이 `2026-08`이면 `2025-08` 기후로 산출된 S 값을 표시
- 종 목록은 S 값 내림차순. 출현 여부의 임계값이나 새로운 위험도 산식은 적용하지 않음
- GBIF 주변 기록은 원본의 항만 반경 100km 학습용 기록. 기록이 없다는 것은 실제 부재를 뜻하지 않음

원본 물동량 2021.09 이후에는 국가 합계를 분배한 추정값이 포함됩니다. S는 서식 적합도이며 실제 출현·유입확률이 아닙니다. 원본의 외삽·연보 적용 범위 등 상세 한계는 `data/SOURCE_NOTES.md`에 보존했습니다. 현재 표는 등록된 항만 자료를 보여주며 DRO 계산 대상 선별 결과를 뜻하지 않습니다.

## 산식 연결이 필요한 부분

현재 검사량은 업로드한 `inspection` 값이 있을 때만 표시합니다. 전월 비교는 `previous_inspection` 또는 같은 파일의 전월 `inspection`으로 계산합니다. 이 값의 단위는 원본 단위입니다. 인원, 컨테이너 건수, TEU의 변환을 임의로 적용하지 않습니다.

다음 달 슬라이더와 숫자 입력은 예상 TEU를 변경합니다. 검사량 산식·총자원 C·출력 단위가 확정되지 않아 예상 검사량은 `산식 연결 대기`로 남깁니다. 연결 위치는 `app.js`의 `resetForecast`와 물동량 입력 이벤트입니다. 실제 DRO 계산을 실행하거나 임의 검사량을 생성하지 않습니다.

현재 날씨는 Open-Meteo의 항만 좌표 기상입니다. 선택한 과거 연월의 실제 날씨가 아니며, 별도로 표시하는 모형 기준 기후와 구분합니다.

## 구성

- `index.html`, `dashboard.css`: 화면과 반응형 레이아웃
- `app.js`: 업로드·화면 전환·상세·날씨·슬라이더
- `model.js`: 열 인식, 입력 검증, 연월·항만 연결과 합산
- `data/reference.js`, `data/suitability/*.js`: 원본에서 추출한 기준자료
- `vendor/`: SheetJS 0.20.3와 Apache-2.0 라이선스
